## 3. Sub-phase F4.2 Architecture & Contract Specifications

### A. Core Architecture (`src/mcp.ts`)
Instead of reinventing STDIO transport and JSON-RPC framing logic, `src/mcp.ts` will integrate `@modelcontextprotocol/sdk`:

```typescript
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { ListToolsRequestSchema, CallToolRequestSchema } from "@modelcontextprotocol/sdk/types.js";
import { StorageEngine } from "./storage";
```

### B. Exposed MCP Tools Schema
The MCP server will register 5 tools delegating directly to `StorageEngine`:
1. `openmemory_status`: Returns structured Markdown context summary (`storage.formatProjectContextSummary()`).
2. `openmemory_get_handoff`: Returns handoff markdown content (`storage.getOrInitHandoff()`).
3. `openmemory_save_adr`: Accepts `{ title, status, date, context, decision, consequences }` and calls `storage.saveADR()`.
4. `openmemory_create_backup`: Accepts `{ label }` and calls `storage.createBackup()`.
5. `openmemory_run_diagnostics`: Calls `storage.runDiagnostics()` and returns diagnostic health report.

### C. Package Dependencies
* Dependencies to install:

## 4. Risks & Mitigation Strategies

| Risk Factor | Impact | Mitigation Strategy |
|---|---|---|
| **Stdout Log Pollution** | High | STDIO transport uses `stdout` for JSON-RPC messages. `src/mcp.ts` will redirect debug logging exclusively to `stderr` or `.openmemory/logs/`. |
| **JSON-RPC Schema Drift** | Low | Managed upstream by `@modelcontextprotocol/sdk`. Zero manual protocol code. |
| **Module Format Compatibility** | Low | `src/mcp.ts` will export both programmatic `runMCPServer()` and direct CLI execution block. |
