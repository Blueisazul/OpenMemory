## 3. Sub-phase F3.5 Technical Objective & Scope

### Objective
F3.5 completes **Phase 3 (Storage Foundation & Core Engine)** by providing:
1. **Automated Backup & Restore Engine (`.openmemory/backups/`):** Atomic snapshots of critical state files (`project-state.json`, `openmemory.json`, `handoff.md`, ADRs) before critical operations or on demand.
2. **Orphaned `.tmp` Cleanup:** Automatic detection and removal of stale temporary files created by interrupted atomic writes.
3. **Diagnostic & Self-Healing Engine (`runDiagnostics`):** Integrity checking for manifest schemas, JSON corruption, Markdown section boundaries, and directory structure.
4. **Programmatic CLI Entrypoint (`src/cli.ts`):** Lightweight command-line interface for memory status inspection, diagnostic runs, backup creation, and cleanups.
5. **OpenCode Plugin Lifecycle Cleanup:** Automatic stale file cleanup on `plugin.initialized` and auto-backup before compaction when enabled in `openmemory.json`.
6. **End-to-End (E2E) Multi-Session Validation Suite:** 8 empirical integration test cases validating the complete system lifecycle under crash and recovery conditions.

## 4. Sub-phase F3.5 Technical Contract Specifications

### A. Data Models & `StorageEngine` Extensions (`src/storage.ts`)

1. **Backup Snapshot Interface:**
   ```typescript
   export interface BackupMetadata {
     id: string; // e.g. "backup-2026-09-25T191000Z"
     timestamp: string;
     label: string;
     filesCount: number;
     backupPath: string;
   }
   ```

2. **Diagnostic Report Interface:**
   ```typescript
   export interface DiagnosticReport {
     status: "HEALTHY" | "REPAIRED" | "CORRUPTED";
     timestamp: string;
     checks: Array<{
       name: string;
       passed: boolean;
       details: string;
     }>;
     orphanedTempFilesRemoved: number;
   }
   ```

3. **New StorageEngine Methods:**
   * `createBackup(label?: string): BackupMetadata`: Copies current state files to `.openmemory/backups/<backup-id>/` atomically.
   * `listBackups(): BackupMetadata[]`: Scans `.openmemory/backups/` and returns sorted list of snapshot records.
   * `restoreBackup(backupId: string): boolean`: Restores state files from specified backup directory safely.
   * `cleanupTempFiles(): number`: Traverses `.openmemory/` directory and unlinks `.tmp` files older than 1 minute or matching test temp patterns.
   * `runDiagnostics(): DiagnosticReport`: Runs comprehensive integrity check and auto-heals corrupted JSON manifests/states.

### B. Programmatic CLI Entrypoint (`src/cli.ts`)
* Executable via `npx tsx src/cli.ts <command> [args]`
* Commands:
  * `status`: Prints project context summary.
  * `backup [label]`: Creates a backup snapshot.
  * `restore <backupId>`: Restores state from a backup snapshot.
  * `diagnostics`: Runs storage engine health check and self-healing diagnostic.
  * `cleanup`: Performs cleanup of stale `.tmp` files.

### C. OpenCode Plugin Integration (`.opencode/plugins/openmemory.ts`)
* Cleans up stale temp files upon `plugin.initialized`.
* Triggers automatic backup on `session.compacted` if `manifest.config.autoHandoffOnCompaction` is `true`.
