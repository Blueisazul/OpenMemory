## 2. Implementation Details

### A. Non-Destructive Installer (`src/installer.ts`)
* **`installOpenMemory(options)`**:
  * Resolves target workspace directory (defaults to `process.cwd()`).
  * Initializes storage via `StorageEngine.ensureStorageStructure()`, ensuring `.openmemory/` directory and default manifest/state/handoff files exist.
  * If `AGENTS.md` exists:
    * Creates timestamped pre-modification atomic backup copy at `.openmemory/backups/AGENTS.md.<timestamp>.bak`.
    * Performs regex replacement (`/<!-- OPENMEMORY:START -->[\s\S]*?<!-- OPENMEMORY:END -->/`) if block exists, or appends delimited block to the end of `AGENTS.md` if block is missing.
    * Preserves all user guidelines, comments, and structure outside the delimiters 100% verbatim.
  * If `AGENTS.md` does not exist and `createAgentsMdIfMissing` is `true`:
    * Creates initial `AGENTS.md` with default guidelines header and delimited block.

### B. Delimited HTML Marker Block
```markdown
<!-- OPENMEMORY:START -->
## OpenMemory Context Pointer
* Active Session Handoff: `.openmemory/handoff.md`
* Active Project State Index: `.openmemory/project-state.json`
* Core Storage Engine: `src/storage.ts`
<!-- OPENMEMORY:END -->
```

### C. CLI Extension (`src/cli.ts`)
Added `case "install"` handling to `runCLI`, outputting installation summary (target path, storage init status, `AGENTS.md` updated status, backup snapshot path).
