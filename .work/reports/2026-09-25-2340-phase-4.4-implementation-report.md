## 2. Implementation Details

### A. Packaging Structure (`dist/`)
Running `npm run build` compiles `src/` TypeScript source files into `dist/` with JS, TypeScript type definitions (`.d.ts`), and source maps (`.js.map`):
```
dist/
├── cli.d.ts
├── cli.js
├── cli.js.map
├── index.d.ts
├── index.js
├── index.js.map
├── installer.d.ts
├── installer.js
├── installer.js.map
├── mcp.d.ts
├── mcp.js
├── mcp.js.map
├── storage.d.ts
├── storage.js
└── storage.js.map
```

### B. Dry-Run Tarball Inspection (`npm pack --dry-run`)
Tarball generated by `npm pack` strictly contains:
- Compiled `dist/` JS & `.d.ts` binaries
- OpenCode operational skills and plugin (`.opencode/`)
- MCP configuration template (`mcp_config.json`)
- Project manifest and guidelines (`package.json`, `AGENTS.md`, `README.md`, `LICENSE`)

Excludes internal development artifacts (`.work/`, `.openmemory/`, `src/`, `.git/`).
