## 3. Implementation Details

1. **Official OpenMemory Plugin (`.opencode/plugins/openmemory.ts`)**:
   * Imports `StorageEngine` from `src/storage`.
   * Automatically initializes `.openmemory/` directory hierarchy non-destructively on load.
   * **`session.created` Hook**: Loads `project-state.json` and `handoff.md`, increments `sessionRunCount`, records `lastSessionId`, updates `lastActiveTimestamp`, sets `currentStatus = "SESSION_ACTIVE"`, and persists updated state atomically.
   * **`session.idle` Hook**: Intercepts idle turn state, saves checkpoint status `IDLE_CHECKPOINT_SAVED` to `project-state.json`, avoiding redundant writes.
   * **`session.compacted` Hook**: Intercepts context compaction events, updates `currentStatus = "COMPACTION_CHECKPOINT_SAVED"`, and records payload evidence dump to `.work/evidence/opencode-compaction-payload.json`.

## 9. Risks & Mitigations

* **Risk**: Excessive disk I/O on rapid agent turns.
* **Mitigation**: `session.idle` checks if `currentStatus` is already `IDLE_CHECKPOINT_SAVED` before writing to prevent redundant disk operations.
