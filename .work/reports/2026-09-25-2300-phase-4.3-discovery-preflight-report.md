## 3. Technical Contract & Architectural Specifications (`src/installer.ts`)

### A. Data Models & Interfaces
```typescript
export interface InstallationOptions {
  targetDir?: string;
  createAgentsMdIfMissing?: boolean;
}

export interface InstallationResult {
  success: boolean;
  storageInitialized: boolean;
  agentsMdUpdated: boolean;
  backupCreated: string | null;
  targetAgentsMdPath: string;
}
```

### B. Core Delimited Marker Block Specification
```markdown
<!-- OPENMEMORY:START -->
## OpenMemory Context Pointer
* Active Session Handoff: `.openmemory/handoff.md`
* Active Project State Index: `.openmemory/project-state.json`
* Core Storage Engine: `src/storage.ts`
<!-- OPENMEMORY:END -->
```

### C. Installer Algorithm (`installOpenMemory`)
1. **Target Workspace Resolution:** Determines `targetDir` (defaults to `process.cwd()`).
2. **Storage Structure Guarantee:** Initializes `StorageEngine` and calls `storage.ensureStorageStructure()`.
3. **Pre-modification Backup Creation:** If `AGENTS.md` exists in `targetDir`, creates timestamped snapshot in `.openmemory/backups/AGENTS.md.<timestamp>.bak` via `storage.atomicWriteFileSync()`.
4. **Idempotent Delimited Block Injection:**
   - If `AGENTS.md` contains `<!-- OPENMEMORY:START -->`, replaces text between `START` and `END` markers.
   - If `AGENTS.md` does not contain markers, appends the delimited block to the end of `AGENTS.md`.
   - If `AGENTS.md` does not exist and `createAgentsMdIfMissing` is `true`, creates `AGENTS.md` with the delimited block.
5. **Atomic File Write:** Writes updated content using `storage.atomicWriteFileSync()`.
6. **CLI Integration:** Extends `src/cli.ts` to support `npx openmemory install`.

## 4. Risks & Mitigation Strategies

| Risk Factor | Impact | Mitigation Strategy |
|---|---|---|
| **Accidental Overwrite of Developer Notes** | High | Pre-modification atomic backup is executed before any edit to `AGENTS.md`. Content outside `<!-- OPENMEMORY:START -->` markers is preserved verbatim. |
| **Duplicate Block Injections** | Medium | Regex matching `<!-- OPENMEMORY:START -->[\s\S]*?<!-- OPENMEMORY:END -->` ensures strict idempotency regardless of how many times `installOpenMemory()` is called. |
| **Missing Directory Permission** | Low | Handled gracefully with explicit try-catch blocks returning `success: false` and error messages in CLI. |
