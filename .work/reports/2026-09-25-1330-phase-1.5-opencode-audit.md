## Technical Findings
1. **OpenCode Event Hooks**: `session.created` is a stable event triggered when a new user session is initialized. `session.compacted` is triggered post-summarization; however, whether it delivers the summary string or requires reading SQLite state must be empirically verified via a live logger spike in Phase 2 (`REQUIERE SPIKE`).
2. **License Safety**: `thedotmack/claude-mem` uses AGPL-3.0. Direct code copy or dependency presents an unacceptable copyleft risk for OpenMemory (MIT). We adopt a clean-room implementation policy.
3. **Operational Memory vs Project Memory**: `.work/` handles temporary execution state during active sessions, whereas `.openmemory/` stores consolidated Git-persisted project memory (ADRs, project state, task handoffs).
