# OpenMemory Command: /handoff

Instrucciones para el agente OpenCode:
1. Lee el archivo `.openmemory/handoff.md`.
2. Presentación del estado de traspaso:
   - Resumen del objetivo activo y fase actual.
   - Resumen del progreso completado (`## Progress Summary`).
   - Decisiones arquitectónicas clave (`## Key Architectural Decisions`).
   - Siguientes pasos pendientes (`## Uncommitted Work & Next Steps`).
3. Muestra el resumen directamente al usuario garantizando la continuidad contextual entre sesiones.
